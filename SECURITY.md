# Security policy
Please do not publicly disclose vulnerabilities before maintainers have assessed them. Open a private GitHub security advisory in your fork or future repository.

Never commit real API keys, user data, `.env` files, database dumps or private Parquet datasets.

This v0.1.0 codebase is a portfolio-grade production-oriented starter and has not undergone independent penetration testing. See `docs/architecture.md` for limitations and required hardening.
